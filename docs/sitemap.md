# Sitemap - Le Son Website (webchinhthuc)

## 1. Overview
Cấu trúc điều hướng và phân trang chính cho website Lê Sơn:

```
/ (Trang chủ)
├── #about (Giới thiệu)
├── #services (Dịch vụ / Sản phẩm)
├── #features (Điểm nổi bật / Công nghệ)
├── #projects (Dự án / Case Studies)
├── #testimonials (Đánh giá khách hàng)
└── #contact (Liên hệ & Đặt lịch)
```

## 2. Main Navigation Routes
- `/`: Trang chủ tổng quan giới thiệu năng lực, giải pháp và dịch vụ.
- `/services`: Chi tiết các gói dịch vụ & bảng giá.
- `/about`: Lịch sử hình thành, đội ngũ chuyên gia, tầm nhìn & sứ mệnh.
- `/contact`: Kênh liên hệ, form tư vấn, bản đồ & thông tin mạng xã hội.

- Kênh liên hệ khẩn cấp / Hotline
