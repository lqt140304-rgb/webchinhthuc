# Design System - Le Son Website

## 1. Color Palette
- **Primary / Brand:**
  - Deep Blue: `#0f172a` (Slate 900)
  - Primary Accent: `#2563eb` (Blue 600) / `#3b82f6` (Blue 500)
- **Secondary / Supporting:**
  - Teal / Emerald: `#059669` (Emerald 600) / `#10b981` (Emerald 500)
  - Indigo: `#4f46e5` (Indigo 600)
- **Neutrals:**
  - Background Light: `#f8fafc` (Slate 50)
  - Background Card: `#ffffff`
  - Text Primary: `#0f172a` (Slate 900)
  - Text Secondary: `#64748b` (Slate 500)
  - Border: `#e2e8f0` (Slate 200)

## 2. Typography
- **Font Sans:** Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif
- **Font Mono:** JetBrains Mono, Fira Code, Consolas, monospace
- **Scale:**
  - H1: 2.5rem - 3.5rem (Bold / Extrabold, tracking-tight)
  - H2: 2rem - 2.5rem (Bold)
  - H3: 1.5rem - 1.75rem (Semibold)
  - Body: 1rem (16px), line-height 1.6
  - Small / Caption: 0.875rem (14px)

## 3. UI Components
- **Buttons:**
  - Primary: Solid blue background with smooth hover & active scaling (`active:scale-95`).
  - Secondary: Outlined slate border with subtle hover background.
  - Ghost / Text: Transparent with hover highlight.
- **Cards:**
  - Rounded corners (`rounded-2xl`).
  - Subtle borders (`border border-slate-200/60`).
  - Soft elevation shadow with smooth hover lift.
- **Icons:**
  - Lucide React (stroke width 1.75 - 2px).
