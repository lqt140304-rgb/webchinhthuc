## 4. Điểm trong báo cáo bàn giao cần kiểm khi có host

- Bàn giao viết rằng mọi Preview Deployment "đều được Vercel tự động bảo vệ bằng header `X-Robots-Tag: noindex`". Claude **chưa kiểm chứng** điều này. Khi có URL, sẽ kiểm bằng HTTP thật:
  - Header của Preview URL.
  - Tách riêng phần header do `vercel.json` đặt (áp dụng cả cho Production) với phần do nền tảng Vercel thêm cho Preview.
  - Có bật Deployment Protection hay không.
- **Soft 404:** bàn giao xác nhận URL không tồn tại vẫn trả HTTP 200 (rewrite SPA), và hẹn xử lý bằng Edge Middleware ở Giai đoạn 4. Khi có host, Claude sẽ ghi lại status và header thực tế, rồi phân loại theo yêu cầu A05.

## 5. Việc cần làm để mở khóa QA trên Vercel

**Chủ dự án hoặc Antigravity gửi Claude:**

1. Preview URL dạng commit, ví dụ `https://<project>-<hash>-<team>.vercel.app`.
2. Deployment ID, hoặc ảnh chụp trang Deployment trên Vercel có ghi commit `db78738`.
3. Cho biết Deployment Protection (Vercel Authentication) bật hay tắt. Nếu bật, cần cấp bypass token để Claude truy cập được.

**Khi nhận đủ, Claude sẽ chạy toàn bộ Directive 012-B:**
